# 1. グリッドの遠近感を強化

## 現状の問題

グリッドの横線が一定間隔で描画されているため、奥行き感が弱い。

現状では平面的に見えやすく、プレイヤーが前進している感覚が不足している。

---

## 新仕様

グリッドはワールド座標上では等間隔を維持する。

例

```python
z = 0
z = 100
z = 200
z = 300
...
```

しかし描画時には透視変換を適用し、

奥へ行くほど横線同士の見た目上の間隔が狭くなること。

---

## 必須要件

以下のような見え方を実現すること。

```text
----------------

----------------

---------------

--------------

-------------

-----------

---------
```

奥へ行くほど密集して見えること。

---

## 注意事項

グリッドそのもののワールド座標を変更してはならない。

以下は禁止。

```python
z = 0
z = 100
z = 150
z = 180
...
```

ワールド座標は等間隔のままとし、

描画変換によって遠近感を表現すること。

例

```python
GRID_COLOR = (0, 255, 0)
```

# 5. 岩の出現数をさらに削減

## 現状の問題

岩の数が依然として多く、

プレイヤーの移動を妨げている。

---

## 新仕様

岩の出現数を極端に減らす。

---

## 推奨値

```python
MIN_ROCK_COUNT = 1
MAX_ROCK_COUNT = 3
```

---

## 配置目的

岩は障害物というよりも

```text
ランドマーク
目印
遮蔽物
```

として機能させる。

---

## 禁止事項

以下のような状況を作ってはならない。

- プレイヤーが頻繁に岩へ衝突する
    
- プレイヤーが進行ルートを失う
    
- 岩だけで画面が埋まる
    

---

# 6. 弾丸と岩の衝突仕様の変更

## 現状仕様

弾丸は岩へ命中すると消滅する。

---

## 新仕様

この仕様を撤廃する。

---

## 新しい挙動

弾丸は岩を通過する。

```python
bullet -> rock
```

↓

```python
通過
```

---

## 衝突判定

弾丸と岩の衝突判定を行わない。

---

## 削除対象

以下の処理を削除すること。

```python
if bullet.collides(rock):
    bullet.destroy()
```

---

## 理由

本ゲームは爽快感を重視する。

岩によって射線が遮られると、

プレイヤーのストレス要因となるため。

---

# 7. 実装上の重要事項

- グリッドのワールド座標は等間隔を維持すること
    
- 描画変換によって遠近感を表現すること
    
- 奥へ行くほど横線の見た目上の間隔を狭くすること
    
- グリッド線の色は緑色とすること
    
- 背景は黒を基調とすること
    
- サイバー空間風の世界観を採用すること
    
- 岩の数は1～3個程度まで削減すること
    
- 岩はランドマークおよび遮蔽物として扱うこと
    
- 弾丸は岩の影響を受けないこと
    
- 弾丸と岩の衝突判定を削除すること
    
- 爽快感を優先すること
