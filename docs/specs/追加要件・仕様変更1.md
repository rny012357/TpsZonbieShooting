# 1. プレイヤー移動とカメラ方式の変更

## 目的

プレイヤーのみが移動しているように見える不自然な挙動を解消する。

TPSゲームらしく、プレイヤーを中心としたカメラ視点を実現する。

---

## プレイヤーのワールド座標

プレイヤーは実際にワールド内を移動する。

保持情報

```python
player.x
player.z
```

---

## プレイヤー描画

プレイヤーは常に画面下部中央付近へ描画する。

例

```python
PLAYER_SCREEN_X = 640
PLAYER_SCREEN_Y = 600
```

プレイヤーのワールド座標を直接画面座標へ変換してはならない。

---

## カメラ方式

すべてのオブジェクトはプレイヤー基準の相対座標で描画する。

```python
relative_x = object.x - player.x
relative_z = object.z - player.z
```

描画計算には必ず相対座標を使用すること。

---

## 左右移動

プレイヤーが右へ移動した場合

```python
player.x += speed
```

描画上は

- ゾンビ
    
- 岩
    
- 障害物
    

が左へ移動して見える。

---

プレイヤーが左へ移動した場合

```python
player.x -= speed
```

描画上は

- ゾンビ
    
- 岩
    
- 障害物
    

が右へ移動して見える。

---

## 前進

プレイヤーが前進した場合

```python
player.z += speed
```

描画上は

- ゾンビ
    
- 岩
    
- 障害物
    

が手前へ近づいて見える。

---

# 2. プレイヤーz座標固定仕様の廃止

以下の仕様を削除する。

```python
player.z = 0
```

プレイヤーはx座標・z座標の両方を移動可能とする。

---

# 3. 岩オブジェクトの追加

## 目的

プレイヤーの移動量や奥行き感を分かりやすくする。

---

## 配置

ステージ開始時にランダム配置する。

例

```python
x = random(-300, 300)
z = random(100, 1000)
```

---

## 挙動

岩は移動しない。

---

## 当たり判定

岩は以下のオブジェクトと衝突判定を持つ。

### プレイヤー

接触した場合

- それ以上移動できない
    

---

### ゾンビ

接触した場合

- 停止する
    

MVP段階では回避AIは実装しない。

---

## 描画

岩も通常オブジェクトと同様に疑似3D描画を行う。

---

# 4. クロスヘアの削除

画面中央のクロスヘアを廃止する。

以下の機能も削除する。

```python
draw_crosshair()
```

UIおよびコードから完全に取り除くこと。

---

# 5. オブジェクトの消滅条件

## ゾンビ

プレイヤーを通り過ぎた場合は消滅する。

条件例

```python
relative_z < 0
```

または

```python
z < player.z
```

---

## 岩

プレイヤーが通過した岩も消滅させる。

条件例

```python
z < player.z
```

---

## 将来的な障害物

プレイヤーが通過した時点で消滅させる。

---

# 6. ウェーブシステム

## 基本仕様

一定数のゾンビを撃破すると次のウェーブへ進行する。

---

## ゾンビHP

Wave1

```python
hp = 1
```

銃弾1発で撃破可能。

---

Wave2以降

ウェーブごとにHPを増加させる。

例

```python
zombie_hp = wave
```

例

```text
Wave1 = 1
Wave2 = 2
Wave3 = 3
Wave4 = 4
```

---

## ウェーブ表示

画面右上へ表示する。

例

```text
Wave 1
Wave 2
Wave 3
```

---

# 7. 水平線と遠近法の調整

## 画面サイズ

```text
1280 × 720
```

---

## 水平線

画面中央へ配置する。

```python
HORIZON_Y = 360
```

---

## 描画基準

ワールド座標

```python
z = 1000
```

を描画する際

```python
screen_y = 360
```

となるようにする。

---

## 描画変換

以下を満たすこと。

```text
z = player.z
↓
画面下部付近

z = player.z + 1000
↓
画面中央（y = 360）
```

---

## 目的

- 遠近感の強化
    
- TPSらしい視界の実現
    
- プレイヤーの進行方向を分かりやすくする
    

---

# 8. 実装上の重要事項

- プレイヤーはワールド内を実際に移動すること
    
- プレイヤーは画面上では固定位置へ描画すること
    
- 描画時はプレイヤー基準の相対座標を使用すること
    
- プレイヤーの左右移動に応じてオブジェクトが相対的に流れて見えること
    
- プレイヤーの前進に応じてオブジェクトが手前へ近づいて見えること
    
- 岩は衝突判定を持つこと
    
- クロスヘアは実装しないこと
    
- プレイヤー通過後のオブジェクトは消滅させること
    
- ウェーブごとにゾンビHPを増加させること
    
- 水平線は画面中央へ固定すること
    
- 疑似3D描画はプレイヤー基準の相対座標で行うこと
