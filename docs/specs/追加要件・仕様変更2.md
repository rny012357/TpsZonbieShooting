# 1. 岩オブジェクト配置の調整

## 目的

プレイヤーの移動ストレスを軽減しつつ、奥行き感を維持する。

---

## 配置数

岩の出現数を大幅に削減する。

推奨値

```python
MIN_ROCK_COUNT = 3
MAX_ROCK_COUNT = 8
```

---

## 配置ルール

岩同士が近すぎる位置に生成されないこと。

```python
distance(rock_a, rock_b) > MIN_ROCK_DISTANCE
```

---

## 通路の確保

プレイヤーが必ず前進できるルートを確保すること。

以下のような完全封鎖配置は禁止する。

```text
岩 岩 岩
岩 岩 岩
岩 岩 岩
```

---

# 2. 岩を遮蔽物として扱う

## 基本仕様

岩は単なる障害物ではなく遮蔽物として機能する。

---

## プレイヤー

岩と衝突した場合

- 通過できない
    

---

## ゾンビ

岩と衝突した場合

- 通過できない
    
- MVP段階では停止する
    

---

## 銃弾

岩と衝突した場合

- 銃弾を消滅させる
    

```python
if bullet.collides(rock):
    bullet.destroy()
```

---

## 効果

プレイヤーは岩を利用して

- ゾンビの進行を妨害できる
    
- 身を隠せる
    

ようになる。

---

# 3. 射撃方式の変更

## 長押し連射

SPACEキーを押し続けている間、

一定間隔で弾丸を発射する。

---

## 発射間隔

```python
FIRE_INTERVAL = 0.15
```

---

## 実装方式

```python
if current_time - last_fire_time >= FIRE_INTERVAL:
    fire()
```

クールダウン方式で管理すること。

```python

x = -200
x = -100
x = 0
x = 100

```

に配置する。

## 描画

各縦線は

(x, z_start)

# 7. マス目形成

縦線と横線は同一座標系を共有する。

結果として規則的なマス目を形成すること。

# 8. グリッド原点の固定

## 原点

```python
x = 0
z = 0
```

---

## 禁止事項

以下は禁止する。

```python
grid_origin = player.position
```

---

## 正しい実装

```python
relative_x = grid_x - player.x
relative_z = grid_z - player.z
```

グリッドはワールド座標へ固定し、

描画時のみ相対座標へ変換すること。

# 9. 岩の当たり判定と描画サイズの分離

## 目的

疑似3Dではz座標に応じて見た目のサイズが変化する。

描画サイズと当たり判定サイズを同一にすると、

- 当たり判定が不安定になる
    
- プレイヤーが見た目と違う場所で衝突する
    
- デバッグが難しくなる
    

という問題が発生する。

---

## 新仕様

岩は以下の2つを別々に管理する。

```python
rock.sprite
rock.collision_radius
```

---

## 描画サイズ

描画サイズはz座標によって変化する。

例

```python
draw_scale =
    1 / (1 + z * SCALE_FACTOR)
```

---

## 当たり判定サイズ

当たり判定はワールド座標基準で固定する。

例

```python
ROCK_COLLISION_RADIUS = 40
```

---

## 衝突判定

プレイヤー

```python
distance(player, rock)
<
ROCK_COLLISION_RADIUS
```

---

ゾンビ

```python
distance(zombie, rock)
<
ROCK_COLLISION_RADIUS
```

---

銃弾

```python
distance(bullet, rock)
<
ROCK_COLLISION_RADIUS
```

---

## 重要事項

- 描画サイズで衝突判定してはならない
    
- collision_radius を使用すること
    
- collision_radius はワールド座標で管理すること
    
- 描画サイズ変更によって当たり判定を変更してはならない
    

---

# 10. 描画の整合性

以下のオブジェクトは全て同じワールド座標系を共有する。

- プレイヤー
    
- ゾンビ
    
- 岩
    
- 銃弾
    
- グリッド
    

描画時のみ

```python
relative_x = object.x - player.x
relative_z = object.z - player.z
```

へ変換する。

---

# 11. 実装上の重要事項

- 岩の数を大幅に減らすこと
    
- プレイヤー進路を完全封鎖しないこと
    
- SPACE長押し連射を実装すること
    
- クールダウン方式で発射を管理すること
    
- 岩は遮蔽物として機能すること
    
- 弾丸は岩へ命中すると消滅すること
    
- グリッドはワールド座標に対応すること
    
- グリッド原点は (0, 0) に固定すること
    
- グリッドはプレイヤー位置から2000以上先まで描画すること
    
- グリッドは規則的なマス目を形成すること
    
- グリッドも相対座標で描画すること
    
- 描画サイズと当たり判定サイズを分離すること
    
- 岩は collision_radius を持つこと
    
- 当たり判定はワールド座標で行うこと
    
- すべてのオブジェクトは同一ワールド座標系で管理すること
