## 1. 概要

PythonおよびPygameを用いて、疑似3D表現によるTPS（Third Person Shooter）型のゾンビシューティングゲームを制作する。

本ゲームは2D描画のみを使用するが、全オブジェクトに奥行き値（z座標）を持たせることで3D空間を疑似的に表現する。

プレイヤーは画面手前に固定され、奥から迫るゾンビを銃で撃退しながら生存を目指す。

# 4. ワールド座標設計

## 基本方針

ゲーム内の全オブジェクトは以下のワールド座標を持つ。

```python
x  # 左右位置
z  # 奥行き位置
```

ゲームロジックではy座標を使用しない。

描画時のみ画面座標へ変換する。

---

## ワールド範囲

```python
x = -300 ～ 300
z = 0 ～ 1000
```

---

## プレイヤー座標

プレイヤーは常に手前に固定する。

```python
player.z = 0
```

プレイヤーの前進はワールド側を移動させることで表現する。

---

# 5. 疑似3D描画

## 描画座標変換

ワールド座標

```python
(x, z)
```

を画面座標へ変換する。

例

```python
screen_x = CENTER_X + x * scale
screen_y = GROUND_Y - z * PERSPECTIVE
```

---

## スプライト拡縮

奥行きに応じてサイズを変更する。

例

```python
scale = 1 / (1 + z * SCALE_FACTOR)
```

特徴

- 奥ほど小さい
    
- 手前ほど大きい
    

---

## 描画順

描画前にz座標でソートする。

```python
objects.sort(
    key=lambda obj: obj.z,
    reverse=True
)
```

描画順

1. 奥のオブジェクト
    
2. 手前のオブジェクト
    

---

## 遠近感

奥に行くほど

- サイズを縮小
    
- 左右移動量を圧縮
    

することで遠近感を表現する。

# 10. 当たり判定

## 判定方法

ワールド座標で判定する。

画面座標は使用しない。

---

## 弾とゾンビ

```python
abs(bullet.x - zombie.x) < HIT_X
and
abs(bullet.z - zombie.z) < HIT_Z
```

を満たした場合に命中とする。

---

## ゾンビとプレイヤー

```python
z <= ATTACK_DISTANCE
```

で攻撃可能状態とする。
